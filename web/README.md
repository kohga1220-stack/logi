# Logi 翻訳機

日本語か英語の文を入れると、Logi に訳すウェブページです。サーバーは要りません。`index.html` をブラウザで開くだけで動き、入力は外に送られません。

```
web/
├── index.html      画面（入力欄と、下に Logi の訳）
├── translator.js   翻訳ロジック（ブラウザと Node の両方で動く）
├── lexicon.js      辞書データ（自動生成。編集しない）
└── test/           Node のテスト
```

## 使い方

- `web/index.html` をブラウザで開く。
- または `python -m http.server -d web` を実行して `http://localhost:8000` を開く。

入力言語は自動判定です。日本語・English のボタンで固定もできます。出力の下に、語ごとの意味（日本語・英語）と注意書きが出ます。

## 仕組みと限界

これは機械翻訳ではありません。`dictionary/final.csv` の語（active のみ、2,747語）と、決まった文型のルールで変換します。

- **日本語**: 辞書の語を最長一致で切り出し、助詞（は・が・を・へ・で・と・の・から・より など）で主語・目的語・前置詞句に分けて、SVO に並べ替えます。動詞は活用形（ます形・た形・ない形・ている・てしまう・可能形・なければならない）を辞書の動詞から作ります。
- **英語**: 助動詞（do / will / can / must など）・be 動詞・完了・進行・否定・疑問（yes/no と what/who/where/when/why/how）・比較・関係節・動名詞を扱います。動詞の過去形・過去分詞は規則変化と主な不規則変化に対応します。
- **数字**: 算用数字と英語の数詞を `docs/grammar.md` §5 の数詞（例: 2025 → `to mipulu ni kupulu to pulu pe`）にします。
- **接続語**: 節をつなぐ語に対応します（取り決めは `docs/grammar.md` §10.3.1）。

  | 入力 | Logi |
  |---|---|
  | しかし・〜が・〜けど / but | `A, patu B.` |
  | だから（文頭）/ so | `A, sonu B.` |
  | なぜなら・〜から・〜ので / because | `pikosu A, B.` |
  | 〜とき / when | `wenute A, B.` |
  | 〜間・〜ながら / while | `wailu A, B.` |
  | 〜前に / before | `pipolu A, B.` |
  | 〜後で・〜てから / after | `aputi A, B.` |
  | 〜まで / until | `utilu A, B.` |
  | 〜のに / although | `oluto A, B.` |
  | unless | `B, ulesu A.` |
  | そして・〜て / and・or（節） | `A, e B.` / `A, o B.` |
  | もし A なら・〜ば・〜たら / if A | `ipu A, B.` |
  | 〜だろうに / if I were ~, I would ~ | `ipu A wutu …, B wutu ….` |
  | 〜と思う・言う / think (that) ~ | `mi omo [節].` |

  従属接続語（`pikosu`・`wenute`・`ipu` など）は、その節の頭に付けます。節の順序は原文のままです（`B because A` は `B, pikosu A.`）。主語のない節は、前の節の主語を引き継ぎます。名詞の並び（A、B and C）は `e` でつなぎます。
- **対応する文型**: 時制（過去・未来）、進行・完了、否定、疑問、比較・最上級・同等、関係節（主語の関係節のみ）、動名詞、年齢、前置詞句、授与動詞、法の副詞、接続語。
- **指示詞・返事・数量の疑問**: これ／あれ・この／その／あの（this / that）、ここ／そこ（here / there）、はい／いいえ（Yes, / No,）、いくつ／いくら（how many / how much）、何歳（how old）。それ は前の文を受ける `li` のままです。
- **あいさつ**: こんにちは・さようなら・どうぞ（Hello / Hi・Goodbye / Bye・Please）を、文頭の感動詞 `kelosu`・`kupaju`・`pilisu` にします。文末の「, please」も文頭に置きます。文の途中の「どうぞ」は、あいさつとしては拾いません。
- **日常のあいさつ**: おはよう（ございます）・おやすみ（なさい）・すみません・ごめん（なさい）・ありがとう（ございます）と、Good morning・Good night・Sorry・Excuse me・Thanks を、既存の語の決まった言い方（`kute mola.`・`kute naita.`・`mi pio moke.`・`mi tanako tu.`）にします。文の全体がその言い方のときだけです。
- **命令・依頼・禁止・勧誘**: 英語の命令文・Please …・Don't …・Let's …、日本語の 〜なさい・〜て・〜てください・〜るな・〜ないでください・〜ましょう・〜よう（文末だけ）を、文末が `!` の文にします（命令・依頼・禁止は主語なし、勧誘は主語 `misu`）。「食べるなら」「食べようと」のような、文の途中の形は、命令・勧誘にしません。英語の Thank you は命令にせず `mi tanako tu.` です。
- **許可・依頼・申し出の疑問**: 日本語の 〜てもいいですか・〜てくれませんか・〜てもらえませんか・〜ていただけますか・〜てくださいませんか・〜ましょうか、英語の May I / Could I / Could you (please) / Shall I を、`kani`・`sati` を使った疑問文にします。May I は `kani` で、可能性の may（`mei`）とは別です。
- **平叙文の許可・禁止・不要**: 日本語の 〜てもいい・〜てはいけない（ならない）・〜なくてもいい と、英語の You may・You may not・You do not have to・You need not を、`kani`・`masi no`・`kani no` にします。主語のない日本語は `tu` を補います。可能性の may（He may come.）は `mei` のままです。
- **目的・様態・対比**: 日本語の 〜ために・〜ように・〜一方（で）と、英語の in order to・to + 動詞（目的語や移動の動詞のあと）・as・whereas・on the other hand を、`pote` + 動名詞・`kasolu`・`patu` にします。want to・need to のような補語の to は、目的にしません。

### できないこと

- 辞書にない語は `[語?]` のまま残し、注意書きを出します。
- 使役・目的語を対比する「は」・「あげる／くれる」などは訳せません。例文集の次の4文が該当します: #19, #22, #26, #35。
- 日本語の「〜でなければ」（unless）は、否定の条件と区別できないため訳しません。英語の unless は訳せます。
- 同音異義や文脈での使い分けは判断できません。複数の訳語を持つ語は、辞書の先頭の語を選びます。
- 英語の drink・rest・play のように名詞にも動詞にもなる語は、前後の語（限定詞・代名詞・前置詞）を手がかりに選びます。迷う文では誤ることがあります。
- 動詞の名詞化は、「食べるのが好き」「食べることが好き」「食べるのは楽しい」と、英語の動名詞の主語（Reading books is fun.）に対応します。名詞化した動詞の否定・過去は表せません（省略して注意書きを出します）。
- 英語の複数形は `mene`（多くの）で表します（仕様どおり複数語尾がないため）。
- 否定と進行・完了を同時に使う語順は仕様が未確定なので、時制・相・`no` の順にして注意書きを出します。

### 確認が必要なデータ

`dictionary/glossary_en.csv`（英語の意味）は、`final.csv` の日本語の意味をもとに Claude が書いたもので、人の確認を受けていません。英語の入力が思いどおりに訳されないときは、まずこのファイルを疑ってください。

## 辞書データの更新

辞書（`final.csv`）や英語の意味（`glossary_en.csv`）を変えたら、次を実行します。

```
python tools/build_web.py     # web/lexicon.js を作り直す
python -m pytest              # lexicon.js が最新か、翻訳が例文集と合うかを確かめる
node --test web/test/translator.test.js   # 翻訳機のテストだけ実行
```

`tests/test_web.py` は `lexicon.js` が古いと失敗します。

## テスト

`web/test/translator.test.js` は次を確かめます。

- 例文集（`corpus/examples.csv`）の日本語が、対応する54文について例文集の Logi と一致すること。
- 英語の49文の訳と、接続語の例（日本語と英語）。
- 数字の変換、辞書にない語の扱い、言語の自動判定。
