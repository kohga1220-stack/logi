# 提案 017: 倍・半分・分数（2倍・半分・3分の1）

状態: **決定済み（2026-10-19）**。M1ko が「お任せ」と返事をしたので、Claude がおすすめの A（Q1〜Q3 すべて）を選んで実装した（v0.25）。仕様は docs/grammar.md §5 を参照。例は、翻訳機で出力を確かめた（`iliu pio to taima seme lase tote teliu.`、`pa semuna te`、`to semuna te apa`、`to pulu pepuka`）。

## 1. 何が足りないか

提案013（助数詞・単位）で、「倍」「半分」「〜分の1」は含めないと決めました（`docs/proposals/013` §6）。翻訳機を実際に動かして確かめた、いまの出力です。

| 入力 | 現状の出力 | 問題 |
|---|---|---|
| これは2倍大きい。 | `iliu pio lase.` | 「2倍」が黙って落ち、意味が変わる（警告も出ない）|
| 私の2倍の年齢だ。 | `pio mi to [倍?] aka.` | 「倍」が訳せない |
| リンゴを半分食べる。 | `ito apa alema.` | 語順が崩れ、警告が出る |
| 3分の1。 | `.` | 何も出ない |
| 半分は私のものだ。 | `alema pio mi.` | 「半分」は `alema`（half）で訳せる |
| It is twice as big. | `li pio [twice?].` | `twice` が辞書にない |
| It is three times bigger. | `li pio te taima.` | 「bigger」が落ちる |
| I ate half of the apple. | `mi pasu ito alema [of?] apa.` | `of` が訳せない |
| one third / half an hour | （訳せない）| |

辞書にあるのは、`alema`（半分・half）、`pepuka`（パーセント）、`lajea`（割合）、`taima`（回）です。「倍」「twice」「double」「third」にあたる語は、辞書にありません。

## 2. 手がかり（すでにある決まり）

- 数は名詞の前に置く（`te apa`）。回数は `te taima`（提案013）。
- 比較は `moli` + 形容詞 + `tanute` + 基準、同等は `seme`（提案014）。
- 単位の語は、数 + 単位の語 + 名詞（`to litapa jeta`）。

## 3. 提案

### Q1. 倍（2倍大きい・twice as big）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 新しい語は造らず、同等の比較（`seme`）に、回数（`数 taima`）を前に付ける | `iliu pio to taima seme lase tote teliu.`（これはあれの2倍大きい）。直訳は「これは、あれと同じくらい大きい、が2回」 |
| B | 倍を表す語を、新しく3音節で造る（数のあとに置く）| |
| C | 倍は決めず、翻訳機は警告を出して止める（いまの「黙って落とす」を直す）| |

おすすめは A です。理由は、新しい語が要らず、提案014 の `seme` と提案013 の `taima` を組み合わせるだけだからです。ただし語数が多くなるので、B（短い語を足す）も候補です。

### Q2. 半分・分数（half・3分の1・one third）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 半分は `alema`（辞書の語）。分数は、割る数を `semuna`（順序）にして `alema` と同じ形で言う: N分のM = 名詞 + `semuna` + N の M個分 | `alema apa`（リンゴの半分）、`pa semuna te`（3分の1。直訳は「3番目の1」）|
| B | 分数を表す語（分母・分子）を、新しく造る | |
| C | 半分だけ決め、分数は決めない | |

おすすめは A ですが、「3分の1」の読み方が回りくどいので、実装の前に例を見て確かめてください（B の語を造るほうが短くなります）。

### Q3. 割合（パーセント・割・〜%）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 辞書の `pepuka`（パーセント）を単位の語として、数 + `pepuka` で言う（提案013の単位と同じ）| `to pulu pepuka`（20パーセント）|
| B | 「割」「分」の日本語の言い方を、別に決める | |
| C | 割合は決めない | |

## 5. 決まったあとにやること

1. `docs/grammar.md` §5 に決まりを足し、履歴を足す。
2. 翻訳機に、日本語（〜倍・半分・〜分の〜・〜パーセント）と英語（twice・N times as・half of・one third・percent）を足す。
3. 例文集に例文を足し、テストを追加。B を選んだときは、語を Antigravity に依頼する。

## 6. この提案に含まれないもの

- 小数（0.5・3.14）、割り算・かけ算の計算の言い方、概数（約・およそ）。
- 年齢・値段の「〜倍」の慣用（倍額・倍増）。
