# 提案 022: 〜ている（状態と進行）・〜ようになる・〜ことになる・〜ところだ

状態: **決定済み（2026-10-23）**。M1ko が「おまかせ」と返事をしたので、Claude がおすすめの A（Q1〜Q3 すべて）を選んで実装した（v0.29）。仕様は docs/grammar.md §7 を参照。

**実装で変えた点**:
- 状態の動詞のリスト（Q1）は、提案の「知る・結婚する・住む・持つ・着る・座る・立つ・似る・分かる」に、愛する・信じる・覚える・太る・痩せる・死ぬ・壊れる を足した（辞書にない 似る は効かない）。辞書にある動詞だけが対象。
- 〜ことになる（Q2）は、もとの主語（なる人）を動名詞の前に置いた（`somena pasu poso mi malona nete monata.`）。主語がない文は、`somena` だけ（`somena pasu poso malona nete monata.`）。
- 過去は、〜するところだった（これからだった）が `mi suni pasu ito.`、〜ているところだった が `mi pasu konu ito.`。
- 英語の come to V は、like・love・know・understand など気持ち・理解の動詞が続くときだけ `pekomo` にした（come to see you のような目的の to は、これまでどおり）。
- 〜話せるようになる のような可能形 + ようになる は、未対応のまま（`kani` の位置が決まっていないため）。

## 1. 何が足りないか

辞書には、進行のマーカー `konu`、変化の `pekomo`（提案015）、決める `poso`、すぐに `suni`、完了のマーカー `pinu` があります。しかし、日本語の「〜ている」の2つの意味（動作の進行と、状態）、「〜ようになる」「〜ことになる」「〜ところだ」は、うまく訳せません。翻訳機を実際に動かして確かめた、いまの出力です。

| 入力 | 現状の出力 | 問題 |
|---|---|---|
| 彼は結婚している。| `li konu malo.` | 「結婚している」は状態だが、進行（結婚しつつある）になる |
| 私は彼を知っている。| `mi konu mo li.` | 同上（知っている = 状態）|
| 彼は食べている。（動作）| `li konu ito.` | これでよい形 |
| 窓が開いている。| `winuta konu alo [開?].` | 訳せない（開く が辞書にない。「開いている」は結果の状態）|
| 彼は本を読むようになった。| `kasolu li loto pupa, [なった?].` | 訳せない |
| 私は日本語が話せるようになった。| `kasolu mi kani toko [語?] teia pupa, [なった?].` | 訳せない |
| 来月結婚することになった。| `li pasu pekomo malona nete monata.` | 「なった」は訳せているが、決めたのが他の人という意味が落ちる（誰かが決めた）|
| 今から食べるところだ。| `naui pio [ころ?].` | 訳せない |
| 食べているところだ。| `pio [ころ?].` | 訳せない |
| 食べたところだ。| `pio [ころ?].` | 訳せない |
| I am about to eat. | `mi alo paute.` | 意味が違う（食べることについて存在する）|
| I came to like it. | `mi pasu komo pote laikona li.` | 来て、のために、好きになる（come を移動に読む）|

## 2. 手がかり（すでにある決まり）

- 進行は `konu`（動詞の前、マーカー）。`li konu ito.`（彼は食べている）。
- 受動態は禁止。能動主体が分からないときは `somena`（誰か）を主語に置く（`docs/grammar.md` §7）。
- `pekomo`（成る）は補語に名詞を直接取る。動名詞は名詞として使える（提案018・020）。

## 3. 提案

### Q1. 〜ている（状態と進行）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 状態を表す動詞（知る・結婚する・住む・持つ・着る・座る・立つ・似る・分かる など）の「〜ている」は、`konu` を付けず、ふつうの形にする。そのほかの動詞は、進行（`konu`）のまま。状態の動詞は、翻訳機の中の小さなリストで決める | `li malo.`（結婚している）<br>`mi mo li.`（知っている）<br>`li konu ito.`（食べている。いまのまま）|
| B | 状態用のマーカーを造る | |
| C | 決めない（いまのまま）| |

おすすめは A です。理由は、新しい語が要らず、英語も同じだからです（He is married・I know him は進行形にならない）。リストにない動詞は進行のままなので、間違える場合は、リストに足して直せます。

### Q2. 〜ようになる・〜ことになる

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 〜ようになる = `pekomo` + 動名詞（話すようになる = 話すことになる、の形）。〜ことになる（他の人が決めた）= `somena` を主語にした `poso` + 動名詞（受動態を避ける）| `li pasu pekomo lotona pupa.`（彼は本を読むようになった）<br>`somena pasu poso malona nete monata.`（来月結婚することになった。誰かが決めた）|
| B | どちらも `pekomo` + 動名詞（決めた人は表さない）| `li pasu pekomo malona nete monata.` |
| C | 決めない | |

おすすめは A です。理由は、新しい語が要らず、〜ことになる の「自分が決めたのではない」意味が残るからです。ただし、受け手（結婚する人）が文から消えるので、実装の前に例を見て確かめてください。

### Q3. 〜ところだ（直前・最中・直後）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | これから（〜するところだ）= `suni`（すぐに）を副詞の位置に置く。最中（〜しているところだ）= 進行の `konu` だけ（「ところ」は訳さない）。直後（〜したところだ）= 提案020の `onuli pasu`（〜たばかり）と同じ | `mi suni ito.`（いまから食べるところだ）<br>`mi konu ito.`（食べているところだ）<br>`mi onuli pasu ito.`（食べたところだ）|
| B | 〜するところだ 専用の語を造る | |
| C | 決めない | |

おすすめは A です。理由は、新しい語が要らず、英語（be about to eat・be eating・have just eaten）とも合うからです。
