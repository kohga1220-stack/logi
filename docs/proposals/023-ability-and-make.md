## 1. 何が足りないか

提案015・018・022で、変化（`pekomo`）、動詞に続く表現、〜ようになる、状態の〜ている が決まりました。残っているのは、次の3つです。翻訳機を実際に動かして確かめた、いまの出力です。

| 入力 | 現状の出力 | 問題 |
|---|---|---|
| 私は泳げる。| `mi kani suwimo.` | これでよい形 |
| 私は泳げるようになった。| `kasolu mi kani suwimo, [なった?].` | 訳せない（泳げる = 能力の変化）|
| 私は日本語が話せるようになった。| `kasolu mi kani toko [語?] teia pupa, [なった?].` | 同上 |
| 窓が開いている。| `winuta konu alo [開?].` | 訳せない（辞書に 開く がない。開いた `apele`（adj）はある）|
| ドアが閉まっている。| `tola alo [閉まって?].` | 同上（閉まる がない）|
| They made him a teacher. | `lisu pasu koso titusa tote li.` | 「先生にした」の意味が、授与（先生を彼に〜させた）と混ざる |
| He made me lunch. | `li pasu koso lunusa tote mi.` | 「昼食を作ってくれた」の意味が落ちる（`make` が `koso`（させる）と `meko`（作る）の2語にまたがる）|
| The news made her happy. | `nota pasu koso li ape.` | これでよい形（提案015）|

## 2. 手がかり（すでにある決まり）

- 可能は副詞 `kani`（`mi kani suwimo.`）。副詞の位置は、主語の直後、マーカーの前。
- 変化は `pekomo` + 補語（`li pekomo kole.`）。〜ようになる は `pekomo` + 動名詞（提案022）。
- 〜にする は `koso` + 目的語 + 補語（`mi koso li titusa.` = 彼を先生にする。提案015）。作ってあげる は `meko` + 物 + `pote` + 受け手（提案019）。

## 3. 提案

### Q1. 可能形 + ようになる（泳げるようになった）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | `pekomo` のあとに、`kani`（できる）を副詞として動詞の前に置く。動詞は動名詞にしない。「泳げるようになった」を「泳げる状態になった」と読む | `mi pasu pekomo kani suwimo.`（泳げるようになった）|
| B | 動名詞で表す: `mi pasu pekomo kani suwimona.`（泳げることになった）| |
| C | 決めない | |

おすすめは A です。理由は、新しい語が要らず、「できる」が `kani` で表せるのと同じ位置だからです。ただし、`kani` の位置（`pekomo` の前か後か）は、いまの決まり（マーカーの前）と少し違うので、例を見て確かめてください。

### Q2. 結果の状態の〜ている（開いている・閉まっている）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 変化を表す動詞の「〜ている」（結果の状態）は、対応する形容詞があれば、`pio` + 形容詞にする。形容詞がない動詞は、辞書に追加するまで訳さない（ANTI の追加待ち）| `winuta pio apele.`（窓が開いている）|
| B | 状態用のマーカーを造る | |
| C | 決めない | |

おすすめは A です。理由は、英語（The window is open）が同じ形で、新しい語が要らないからです。この形で訳せる動詞は、辞書に 形容詞（開いた `apele` など）があるものだけです。

### Q3. make + 目的語 + 名詞

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 目的語のあとの名詞が、役割・身分（teacher・king・leader など）のときは、変化の `koso` + 目的語 + 名詞（先生にした）。そのほかの名詞（lunch・coffee など）のときは、作る（`meko`）+ 物 + `pote` + 受け手 | `mi koso li titusa.`（彼を先生にした）<br>`li pasu meko lunusa pote mi.`（昼食を作ってくれた）|
| B | どちらも `koso` のまま（いまのまま）| |
| C | 決めない | |

おすすめは A です。理由は、新しい語が要らず、英語の make の2つの意味（〜にする、作る）を、名詞の種類で分けるのが自然だからです。役割の名詞のリストは、翻訳機の中の小さなリストで決めます（間違える場合は、リストに足して直せます）。
