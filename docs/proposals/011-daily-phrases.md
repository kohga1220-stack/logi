# 提案 011: 日常のあいさつの続き（こんばんは・お元気ですか・願いの言葉）

状態: **決定待ち**。M1ko が Q1〜Q3 を選んだら、Claude が実装します。

## 1. 何が足りないか

提案005（v0.14）で、おはよう・おやすみ・すみません・ありがとうを決めました。そのとき外した、時刻のあいさつと、日常の短い言い方を決めます。翻訳機を実際に動かして確かめた、いまの出力です。

| 入力 | 現状の出力 | 問題 |
|---|---|---|
| こんばんは。 | `[こんばん?].` | 訳せない |
| Good evening. / Good afternoon. | （訳せない）| |
| お元気ですか？ | `pio miwe ka?` | **主語がない**。Logi の平叙文・疑問文は、主語を省かない（§10.3.1）|
| 元気です。 | `pio miwe.` | 同上（主語がないと、命令に見える）|
| How are you? | `tu aua pio ka?` | 「どう」の `aua` が入り、意味が通りにくい |
| I am fine. | `mi pio miwe.` | これでよい形 |
| Good luck. | （訳せない）| |
| Have a nice day. | `oto naise teia!` | `oto`（持つ）で訳され、意味が通らない |
| See you tomorrow. | `sio moloa tote tu!` | 主語がなく（命令に見える）、`tote`（へ）が入って語順がおかしい |
| お元気で。・お大事に。・気をつけて。 | 訳せない | |

## 2. 手がかり（すでにある決まり）

- あいさつは、既存の語の決まった言い方で言う（提案005）。おはよう = `kute mola.`、おやすみ = `kute naita.`。
- こんにちは = `kelosu`（提案002）。
- 語はある: 夕方 `ipa`・午後 `apuja`・元気な `miwe`・運 `luna`・日 `teia`・良い `kute`。

## 3. 提案

### Q1. 時刻のあいさつ（こんばんは・Good evening・Good afternoon）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | おはよう・おやすみと同じ作り（良い + 時間帯）。新しい語なし。Good afternoon は、こんにちは（`kelosu`）と同じ使い方もあるが、翻訳機は、文字どおり `kute apuja.` にする | こんばんは・Good evening = `kute ipa.`<br>Good afternoon = `kute apuja.` |
| B | どれも `kelosu`（こんにちは）にする | `kelosu.` |
| C | 訳さない（いまのまま）| |

おすすめは A です。理由は、提案005の考え方と同じで、新しい語が要らず、意味が見えるからです。

### Q2. お元気ですか・元気です・How are you?

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 主語を補う。疑問は `tu`、平叙は `mi`。How are you? は `tu pio miwe ka?`（「どう」の `aua` は使わない）| `tu pio miwe ka?`（お元気ですか）<br>`mi pio miwe.`（元気です）|
| B | 主語は補わず、いまのまま | `pio miwe ka?` |
| C | How are you? だけ直す（日本語はそのまま）| |

おすすめは A です。理由は、Logi は主語を省かない決まりで、主語がないと、命令（提案003）に見えるからです。「元気」以外の、形容詞だけの文（「寒いです」）も、同じ補い方が使えます。

### Q3. 願いの言葉（Good luck・Have a nice day・See you tomorrow）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 「良い + 名詞」の形（`kute` + 名詞）を、文末 `!` で言う。会う約束は、主語を省かず、未来のマーカー `putu` で言う| Good luck = `kute luna!`<br>Have a nice day = `kute teia!`<br>See you tomorrow = `mi putu sio tu moloa.` |
| B | 専用の感動詞を、3音節で造る | |
| C | 訳さない | |

おすすめは A です。理由は、新しい語が要らず、Q1 の作りと同じだからです。お元気で・お大事に・気をつけて は、意味が日本語に強く結びついているので、この提案に含めません（提案005 Q3 と同じ扱い）。

## 5. 決まったあとにやること

2. 翻訳機に、日本語（こんばんは・お元気ですか・元気です）と、英語（Good evening・Good afternoon・How are you?・Good luck・Have a nice day・See you tomorrow）を足す。主語のない形容詞だけの文に、主語を補う処理は、お元気ですか・元気です の2つに限る。

## 6. この提案に含まれないもの

- お疲れ様・お久しぶり・お大事に・気をつけて・いってらっしゃい（意味が日本語に強く結びついている）。
- 形容詞だけの文に、一般に主語を補うこと（必要になったら別に決める）。
