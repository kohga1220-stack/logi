# 提案 015: 変化（〜になる・〜くなる・〜にする・だんだん・ますます）

状態: **決定済み（2026-10-19）**。M1ko が「お任せ」と返事をしたので、Claude がおすすめの A（Q1〜Q3 すべて）を選んで実装した（v0.23）。仕様は docs/grammar.md §7 を参照。

**実装で変えた点（2点）**: ①「ますます」は、辞書にすでに副詞 `initi`（increasingly）があったので、`moli` ではなく `initi` を使った（`li initi pekomo wuje.`。「もっと寒くなる」は `moli` のまま）。②下の表の「clean は辞書にない」は誤りだった（`kulene` = きれいな / clean がある）。翻訳機が補語の形容詞を取れなかっただけで、いまは `Make the room clean.` も訳せる。

## 1. 何が足りないか

状態の変化を表す語はすでにあります（`pekomo` = become、`kulapi` = gradually、`koso` = させる）。しかし、文法（語順・補語の取り方）が決まっていないため、翻訳機は変化の文を訳せません。翻訳機を実際に動かして確かめた、いまの出力です。

| 入力 | 現状の出力 | 問題 |
|---|---|---|
| 寒くなる。 | `[寒くなる?].` | 訳せない |
| 彼は先生になった。 | `li titusa [なった?].` | 「なる」が訳せない（`pekomo` が使われない）|
| 暗くなってきた。 | `[暗くなってきた?].` | 訳せない |
| だんだん寒くなる。 | `[寒くなる?].` | 同上 |
| ますます忙しくなる。 | `[忙しくなる?].` | 同上 |
| 水が氷になる。 | `jeta aisa [なる?].` | 「なる」が訳せない |
| 水を熱くする。 | `topo jeta ika [く?].` | 「熱く」の「く」が残る |
| It becomes cold. | `li pekomo kolata.` | 補語が名詞 `kolata`（寒さ）になり、形容詞にならない |
| He became a teacher. | （訳せない）| |
| She became happy. | （訳せない）| |
| It is getting colder. | `li konu leso [colder?].` | `leso`（受け取る）が使われ、意味が違う。比較級も訳せない |
| Make the room clean. | `koso luma [clean?]!` | 補語の形容詞が取れない（`clean` は辞書にある）|

## 2. 手がかり（すでにある決まり）

- `pio`（である）は、補語に名詞か形容詞を直接取る（`li pio kole.`、`li pio titusa.`）。
- `pekomo`（なる）は動詞として辞書にある。
- `kulapi`（だんだん）は副詞（語尾 -i）。副詞は主語の直後、マーカーの前（§7）。
- `koso`（させる）は使役の動詞で、いまは動名詞を取る（`mi koso li komona.` = 私は彼を来させる。§7 使役）。
- 比較は `moli` + 形容詞（提案014）。

## 3. 提案

### Q1. 〜になる・〜くなる（変化の補語）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | `pekomo` は `pio` と同じく、補語に名詞か形容詞を直接取る。時制・マーカーは `pekomo` の前 | `li pekomo kole.`（寒くなる）<br>`li pasu pekomo titusa.`（彼は先生になった）<br>`jeta pekomo aisa.`（水が氷になる）|
| B | 変化専用の語（〜になる）を、新しく造る | |
| C | 変化は決めず、訳さない（いまのまま）| |

おすすめは A です。理由は、新しい語が要らず、`pio` と同じ作りで覚えやすいからです。「〜てきた」「〜ていく」は、この提案に含めません（`pekomo` だけで訳し、「きた」「いく」は落とします）。

### Q2. だんだん・ますます（変化の程度）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | だんだん = `kulapi`（主語の直後）。ますます = 補語に `moli`（もっと）を付ける（提案014の比較と同じ形）。**実装では、辞書の副詞 `initi` を使った** | `li kulapi pekomo kole.`（だんだん寒くなる）<br>`li initi pekomo wuje.`（ますます忙しくなる。当初案は `li pekomo moli wuje.`）|
| B | ますます専用の語（moli moli など、繰り返し）を決める | |
| C | だんだん・ますます は訳さず、落とす | |

おすすめは A です。理由は、新しい語が要らず、「ますます」を「もっと」と同じ形で言えるからです。英語の gradually・more and more も、同じ形にします。

### Q3. 〜にする・〜くする（変化をさせる）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | `koso`（させる）+ 目的語 + 補語（名詞か形容詞）。動名詞の使役（`koso li komona`）は、そのまま | `mi koso luma lase.`（部屋を大きくする）<br>`mi koso li titusa.`（彼を先生にする）|
| B | `pekomo` を使い、「〜をなるようにする」と言い換える | |
| C | 〜にする は訳さない（いまは `topo`（する）で、補語が落ちる）| |

おすすめは A です。理由は、`koso` の既存の使い方（目的語のあとに述語）の延長で、新しい語が要らないからです。

## 5. 決まったあとにやること

1. `docs/grammar.md` §7 に決まりを足し、履歴を足す。
2. 翻訳機に、日本語（〜になる・〜くなる・〜になった・〜てきた・〜にする・〜くする・だんだん・ますます）と、英語（become・get・turn + 形容詞・名詞、gradually、more and more、make + 目的語 + 補語）を足す。
3. 例文集に例文を足し、テストを追加。

## 6. この提案に含まれないもの

- 「〜てきた」「〜ていく」の、時間の流れの意味（訳さず落とす）。
- 受け身（なる = 自然にそうなる）、可能（〜ことになった）などの慣用句（「〜ことになる」「〜ようになる」）。
- 形容詞から副詞を作る規則（別の提案）。
- 辞書にない形容詞。語は、Antigravity の追加で増える。
