# 提案 019: 授受（あげる・くれる・もらう・〜てくれる・〜てもらう）

状態: **決定待ち**。提案018より後に決めてかまいません。M1ko が Q1〜Q3 を選んだら、Claude が実装します（「お任せ」でも進められます）。

## 1. 何が足りないか

辞書には、与える `kipo`、受け取る `leso` があります。英語の give / receive / get は、すでに訳せます。しかし、日本語の「あげる・くれる・もらう」と、「〜てくれる・〜てもらう」（恩恵の言い方）は、訳せません（`corpus/examples.csv` の id 19・26 も、日本語からは未対応として扱っています）。翻訳機を実際に動かして確かめた、いまの出力です。

| 入力 | 現状の出力 | 問題 |
|---|---|---|
| 彼は私に本をくれた。| `li mi pupa [くれた?].` | 訳せない |
| 私は彼に本をあげた。| `mi li pupa [あげた?].` | 訳せない |
| 私は彼から本をもらった。| `mi li pupa [らった?].` | 訳せない（語の途中で切れる）|
| 母が私に服を買ってくれた。| `mama puo kulosa tote mi, e [くれた?].` | 訳せない |
| 私は友達に手伝ってもらった。| `mi pulena ena [伝って?] [らった?].` | 訳せない |
| 彼に本を与えた。| `pasu kunano pupa tote li.` | 「与える」は別の語 `kunano` になる（`kipo` は「保つ・与える」）|
| He gave me a book. | `li pasu kipo pupa tote mi.` | これでよい形 |
| I received a book from him. | `mi pasu leso pupa pulomute li.` | これでよい形 |
| She bought me a coat. | （訳せない）| 「me のために買う」は、授与の文型として扱えない |

## 2. 手がかり（すでにある決まり）

- 与える = `kipo` + 目的物 + `tote` + 受け手。受け取る = `leso` + 目的物 + `pulomute` + 与えた人（英語の出力と同じ形）。
- 前置詞 `pote`（のために）がある（提案007）。

## 3. 提案

### Q1. あげる・くれる・もらう（物の授受）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 与える側の動詞を `kipo`、受け取る側を `leso` にして、向きは語順と前置詞で表す。あげる・くれる は同じ（誰が誰に、が文にある）。もらう = `leso` + `pulomute` | `li pasu kipo pupa tote mi.`（彼は私に本をくれた）<br>`mi pasu kipo pupa tote li.`（私は彼に本をあげた）<br>`mi pasu leso pupa pulomute li.`（私は彼から本をもらった）|
| B | くれる・あげる の区別（話し手への向き）を表す語を造る | |
| C | 決めず、訳さない（いまのまま）| |

おすすめは A です。理由は、英語（gave me・gave him）がすでにこの形で、新しい語が要らないからです。日本語の「あげる」と「くれる」の違い（話し手に向かうか）は、`tote mi`（私へ）で見えるので、失われません。

### Q2. 〜てくれる・〜てもらう（恩恵）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 〜てくれる は、元の動詞の文に `pote`（のために）+ 受け手を付ける。〜てもらう は、してくれた人を主語にした文に直す（受け身にしない。`docs/grammar.md` の「受動態: 禁止」）| `mama pasu puo kulosa pote mi.`（母が私に服を買ってくれた。母は私のために服を買った）<br>`pulena pasu elupo mi.`（友達に手伝ってもらった。友達は私を助けた）|
| B | 恩恵を表す語を造る | |
| C | 決めず、訳さない | |

おすすめは A です。理由は、新しい語が要らず、「してくれた人」を主語にした能動態の文にでき、受け身の禁止とも合うからです。「くれた」「もらった」の恩恵の気持ちは、落ちます。

### Q3. 〜てあげる

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | Q2 と同じく、`pote` + 受け手。「してあげる」の恩恵は落ちる | `mi pasu elupo li.`（私は彼を助けてあげた）。受け手が必要なときは `pote li` |
| B | 〜てあげる だけ、別の言い方を決める | |
| C | 決めない | |
