# 提案 001: 指示詞・はい／いいえ・「いくつ／いくら」

状態: **決定済み（2026-10-15）**。M1ko が「おすすめでOK」と返事をしたので、Q1〜Q4 はすべて A で実装した（v0.10）。仕様は docs/grammar.md §4・§6.1・§7 を参照。

## 1. 何が足りないか

日常の会話に必ず出る次の語が、いまの辞書にありません。

| 日本語 | 英語 | いまの扱い |
|---|---|---|
| これ・この／それ・その／あれ・あの | this / that | 無し（`li` が「それ」の意味を兼ねるだけ）|
| ここ・そこ・あそこ | here / there | 副詞 `ili`（ここで）・`teli`（そこで）はある。場所を表す名詞は無い |
| はい／いいえ | yes / no | 無し。`no` は否定マーカーとしてだけある |
| いくつ・いくら | how many / how much | 無し |

## 2. 先に分かった制約: 短い語の空きがほとんど無い

15音で作る辞書は、いまの1,671語でほぼ埋まっています。「既存のどの語とも編集距離2以上」の規則（docs/grammar.md §8.1）を守れる語形を数えました（`python tools/free_forms.py`）。

| 音節数 | 空き形の数 |
|---|---|
| 1音節 | 0個 |
| 2音節 | **114個** |
| 3音節 | 86,772個 |

2音節で空いているのは `tawu`・`taju`・`kepu`・`keki` のような、意味と結びつかない形ばかりです。そのため「this → `tisu`」のように英語から直接造ると、`tusu`（あなたたち）・`misu`（私たち）・`lisu`（彼ら）と1文字違いになります。

## 3. 提案

### 3.1 指示詞（this / that）

`ili`（ここで）と `teli`（そこで）に、機能語の語尾 `-u`（v0.4 で決めた規則）を付けた形を提案します。

| Logi | 意味 | 近い語（編集距離1）|
|---|---|---|
| `iliu` | これ・この（this）| `ili` だけ |
| `teliu` | それ・その・あれ・あの（that）| `teli` だけ |

- 近い語が元の `ili`・`teli` だけなので、規則を満たします。
- 日本語の「この」は「ここの」、「その」は「そこの」という作りなので、意味とも合います。
- **使い方は1つ**: 名詞の前に置けば限定詞（`iliu apa` = このリンゴ）、単独なら代名詞（`iliu pio kute.` = これは良い）。形容詞と同じ位置で、語尾は変えません。
- 複数形は作りません（§5 のとおり `mene`）。these / those は `iliu`・`teliu` のままです。
- 日本語の3分類（これ／それ／あれ）は、英語と同じ2分類にまとめます。**これ → `iliu`、それ・あれ → `teliu`**。ただし、前の文を受ける「それ」は、いまのとおり `li` のままにします。

```
iliu apa pio kute.        （このリンゴは良い）
iliu pio kute.            （これは良い）
mi laiko teliu.           （私はあれが好きだ）
```

### 3.2 場所（ここ・そこ・あそこ）

新しい語は作りません。`ili`・`teli` を、前置詞の目的語としても使えることにします。

```
tu iko tote ili ka?       （あなたはここへ行きますか）
li komo pulomute teli.    （彼はそこから来る）
```

### 3.3 はい／いいえ

| Logi | 意味 | 理由 |
|---|---|---|
| `jesu` | はい（yes）| 英語の yes に `-u`。近い語が無い |
| `no` | いいえ | 否定マーカーをそのまま使う。新しい語は作らない |

```
tu laiko apa ka?
jesu, mi laiko apa.       （はい、私はリンゴが好きです）
no, mi no laiko apa.      （いいえ、私はリンゴが好きではありません）
```

日本語の「はい／いいえ」は、否定の質問への答えが英語と逆になることがあります（「食べないの？」「はい、食べません」）。翻訳機は、この逆転を扱わず、文の意味で訳します。

### 3.4 いくつ・いくら

新しい語は作りません。`aua`（どうやって／how）と `mene`（多くの）を並べます。副詞が形容詞を修飾するときは形容詞の直前に置く規則（§7）のままです。

```
tu oto aua mene apa ka?   （あなたはリンゴをいくつ持っていますか）
li pio aua mene ka?       （それはいくらですか）
tu oto wata ila ka?       （あなたは何歳ですか。年齢は §5 の `mi oto to ila` と同じ形）
```

2. `docs/grammar.md` に §6.1 指示詞、§4 の「はい／いいえ」、§7 の「いくつ」を書き、変更履歴を足す。
3. 翻訳機（`web/translator.js`）に次を足す。
   - 日本語: これ・この・あれ・あの・その・ここ・そこ・あそこ・はい・いいえ・いくつ・いくら・何歳

4. 例文集（`corpus/examples.csv`）に例文を足し、テストを追加。

## 6. この提案に含まれないもの

感動詞（ありがとう・おはよう・こんにちは・さようなら・すみません・どうぞ）は、この提案では扱いません。当面は、既存の語で文として言えます（例: `mi tanako tu.` = ありがとう）。専用の語を造るかは、別の提案にします。
