## 2. 間違いの癖

34 語を、主な理由で分けた（1語につき1つ）。

| 癖 | 語数 | 内容 | 例 |
|---|---|---|---|
| **A. すでにある語と意味が重なる** | 22 | 日常の語がすでにある意味に、別の日本語・英語の語を足す。第15〜24弾に5語、第26弾に1語、第27弾に9語、第28弾に7語 | 飲料（飲み物）、風景（景色）、眠る（寝る）、調整する（調節する）、集う（集まる）、厳格な（厳しい）、乾燥した（乾いた）、友好的な（親しみやすい）、頑強な（丈夫な）、威嚇する（脅迫する） |
| **B. 英語の見出し語の意味が、日本語とずれる** | 10 | 英語の語の主な意味が、日本語と違う | muffler（マフラー = 車の消音器）、greeting（迎え）、maiden（少女。古風）、casually（たまたま）、scenario（脚本）、crude（粗末な）、inaugurate（就任させる） |
| **C. 自動詞・他動詞のずれ、まれな語** | 2 | 日本語は自動詞、英語は他動詞でまれな語 | 呆れる ↔ dumbfound、乱れる ↔ dishevel |

癖Aが 65% を占めます。さらに、次のことが分かりました。

1. **まれな英語の語で、日常の日本語を言い換えている（癖Aの多く）。** slumber・congregate・clamorous・perilous・amicable・stout・arid・serene・intimidate。日常の日本語にはすでに1語の対応（寝る・集まる・うるさい・危険な・親しみやすい・丈夫な・乾いた・脅迫する）があるのに、文語的な英語の語を見出しにして、新しい語として足している。
2. **近い意味の語を、同じバッチの中で2つ足している。** citadel（城塞）と fortress（要塞）。同じバッチの候補どうしを比べる手順がなかった。
3. **英語の類義語は、手で調べることになっていたが、調べられていない。** 第28弾の確認表（PR #104）の「`glossary_en.csv` で調べた同じ品詞の語」の列は、貼られたログのコードでは、60語すべてに同じ文（「同じ品詞（品詞名）の重なりなし」）を入れる作りだった。実際には、friendly（親しみやすい）・sturdy（丈夫な）・threaten（脅迫する）・peaceful（長閑な）が辞書にあった。
4. **重なりが表に出ても、「別の意味」と書いている。** `tools/overlap_check.py` は第28弾の rigid で `sutete`（厳しい）、arid で `tulaie`（乾いた）を出していたが、確認表では「厳格な規律・硬直であり別の意味」「気候や土地の不毛な乾燥であり別の意味」と書かれた。貼られたログの、判断の文は、すべて「…であり別の意味」で終わっていた。どの場面で言い分けるか（例文）は書かれていない。
5. **全60語に `overlap_check.py` を走らせた実行は、貼られたログの範囲では見当たらない。** `viaduct` の1語だけを走らせている。
6. **`source` の列が、語そのものではなく、近い基本語になっている。** 例: 高架橋 → 橋、蒸気船 → 船、万華鏡 → 鏡（`dictionary/anti_additions.csv`）。「国語研教育基本語彙」に入っている根拠として確かめられない。

癖が増えた理由は、日常の基本語を足し終えて、もう1語ある概念の言い換えしか残っていないことだと考えられます（第28弾は、建物・音楽・乗り物のまれな名詞が名詞 30 語の多くを占めた）。これは推測で、数えてはいません。

## 3. ツールの改善（`tools/overlap_check.py`）

癖Aを、足す前に機械で止めるため、次を足した。

- **英語の類義語（WordNet）**: `pip install wn==0.0.23` が入っていれば、見出し語が違っても、同じ意味のまとまりに入る既存語（stout と sturdy、amicable と friendly、beverage と drink）を出す。入っていなければ、その項目だけ出ず、注意を表示する。
- **同じバッチの中の重なり**: 候補どうしで、同じ品詞で日本語・漢字・英語の類義語が近い組を出す（citadel と fortress）。
- **`--table`**: PR 本文に貼る確認表を出す。ツールの結果を先に埋め、強い重なりのある語を先に並べ、「判断」の列は人が書く（固定の文を入れない）。

過去のバッチで、あとから重複と分かった語を、足す前に出せたかを測った（全部で 17 語。辞書は、そのバッチを足す前の状態）。

| ツール | 重複のうち、正しい既存語を出せた数 |
|---|---|
| これまで（日本語の2文字の連なり・漢字・英語の見出し語）| 8 / 17 |
| 改善後（+ WordNet の類義語 + 同じバッチ）| 14 / 17 |

出せなかった 3 語は、uncomfortable（不自由な。既存は inconvenient = 不便な）、trowel（スコップ。既存は shovel = シャベル）、intimidate（威嚇する。既存は threaten = 脅迫する）。うるささも測った。第28弾の 60 語で、重なりが出た語は 43 → 52 語に増えた。そこで、強い重なり（日本語の2文字の連なり、英語の見出し語、類義語）と、漢字が1字共通するだけの弱い重なりを分けた（第28弾で、強い重なりの語は 22 / 60）。WordNet は助言で、近さの判断は人が行う。

## 4. 指示の改善（`docs/WORKFLOW.md` §2 の変更案。別のPRで M1ko が決める）

1. 確認表は、`python tools/overlap_check.py --table` の出力を貼る。手で作らない。固定の文を入れない。
2. 強い重なりのある語は、1語ずつ、「どの場面でどちらを使うか」を例文で1つ書く。例文で言い分けられないときは、同じ意味とみなして、追加しない。
3. 重なりで外した語は、Claude への「併記の依頼」に書く（例: `sutete` に 厳格な を併記してほしい）。ANTI は既存の語を書き換えない決まり（手順3）なので、Claude が反映する。
4. 同じバッチの候補どうしも比べる（ツールが出す）。
5. 英語の見出し語は、日常の日本語に、英語の日常の語で対応するもの。slumber・dwell・congregate のような文語・まれな語で、日常の語（寝る・住む・集まる）を言い換えない。
6. まれな語は、動詞に限らず、1バッチの2割までにする（60語なら12語、50語なら10語）。名詞だけで 30 語にしない。
7. `source` には、その語自身の出典を書く。近い基本語を書かない。出典が確かめられない語は、足さない。
8. 次のバッチの語数は、直前のバッチの【修正推奨】の割合で決める（手順5のまま。1割以下なら増やしてよい、超えたら 50 語）。
