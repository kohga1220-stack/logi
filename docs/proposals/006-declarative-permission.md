# 提案 006: 平叙文での許可・禁止・不要（「食べてもいい」「食べてはいけない」「食べなくてもいい」）

状態: **決定済み（2026-10-16）**。M1ko が「006 すべて A」と返事をしたので、Q1〜Q3 はすべて A で実装した（v0.15）。仕様は docs/grammar.md §4 を参照。

## 1. 何が足りないか

v0.13（提案004）で、疑問文での許可（`mi kani ito apa ka?`）・依頼・申し出を決めました。平叙文の許可・禁止・不要は、決めていません（提案004 §6 で、別の提案にすると書いたものです）。

翻訳機を実際に動かして確かめた、いまの出力です。

| 入力 | 現状の出力 | 問題 |
|---|---|---|
| リンゴを食べてもいい。 | `ito apa, e pio kute.` | 「食べて、そして良い」になり、主語もなく、意味が通りにくい |
| リンゴを食べてもいいよ。 | `ito apa, e kute [よ?].` | 同上。さらに「よ」が訳せない |
| リンゴを食べてもよい。 | `ito apa, e [よい?].` | 訳せない |
| リンゴを食べてはいけない。 | `ito apa, e [いけない?].` | 訳せない |
| リンゴを食べてはならない。 | `ito apa, e ipu pio, [ない?].` | 訳せない |
| リンゴを食べなくてもいい。 | `[食べなくて?] olusi pio kute.` | 訳せない |
| You may eat an apple. | `tu mei ito apa.` | `mei` は「かもしれない」。許可の意味に、合っていない |
| You can eat an apple. | `tu kani ito apa.` | これでよい形 |
| You must not eat an apple. | `tu masi no ito apa.` | これでよい形 |
| You do not have to eat an apple. | `tu no oto [eat?] apa.` | 訳せない |
| You need not eat an apple. | `tu nijo [not?] [eat?] apa.` | 訳せない |

## 2. 手がかり（すでにある決まり）

- 法副詞 `kani`（できる・してよい）・`masi`（ねばならない）は、主語の直後・マーカーの前に置く（§7）。否定マーカー `no` は動詞の前（`mi kani no lano.` = 私は走れない）。
- 提案004で、許可は `kani` と決めた（`mi kani ito apa ka?`）。
- 英語の `You must not eat an apple.` は、すでに `tu masi no ito apa.`（禁止）と訳している。
- 日本語は、主語を省くことが多い。提案004では、許可（〜てもいいですか）の主語を `mi`、依頼の主語を `tu` にした。

## 3. 提案

### Q1. 許可（〜てもいい・〜てもよい・You may / You can）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | `kani` を使う。日本語で主語がないときは、`tu`（あなた）を補う。英語の `You may` は `kani` にする（`mei` にしない）| `tu kani ito apa.`（リンゴを食べてもいい）|
| B | 主語は補わない（日本語で主語がなければ、主語のない文のまま）| `kani ito apa.` |
| C | 許可を表す新しい語を、3音節で造る | |

おすすめは A です。理由は、新しい語が要らず、提案004の疑問文（`mi kani … ka?`）と同じ形になること、主語を省かない Logi の平叙文の決まり（§10.3.1）に合うことです。「食べてもいいよ」のような言い方は、ふつう「あなたは食べてもよい」の意味なので、`tu` を補います（「私は食べてもいい」のように主語があれば、それを使う）。B は、主語のない文が、命令（提案003）と見分けにくくなります。

英語の `may` は、「許可」と「可能性」の2つの意味があります。`You may …`（あなたは〜してよい）は許可、`He may come.`（彼は来るかもしれない）は可能性として、翻訳機は、主語で分けます（2人称の `You may` だけ `kani`。`I may` や、ほかの主語は、これまでどおり `mei`）。

### Q2. 禁止（〜てはいけない・〜てはならない・You must not）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | `masi no`（ねばならない + 否定）を使う。日本語で主語がなければ `tu` を補う | `tu masi no ito apa.`（リンゴを食べてはいけない）|
| B | 提案003の命令の禁止形（`no ito apa!`）で言う | |
| C | 禁止を表す新しい語を造る | |

おすすめは A です。すでに英語の `You must not` が、この形に訳されているので、日本語を同じ形に合わせるだけで済みます。命令の禁止（`no ito apa!`。〜するな）と、状態の禁止（〜してはいけない）は、日本語でも別の言い方なので、別の形にします。

### Q3. 不要（〜なくてもいい・〜なくてもよい・You don't have to / You need not）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | `kani no`（してよい + 否定。しなくてよい）を使う | `tu kani no ito apa.`（リンゴを食べなくてもいい）|
| B | 「ねばならない」を否定する形を、新しく決める（`no` を `masi` の前に置く）| `tu no masi ito apa.` |
| C | 不要の文型は作らず、翻訳機は訳さない | |

おすすめは A です。理由は、新しい決まりが要らないことです（`masi no` = してはならない、`kani no` = しなくてもよい、で、`no` の位置は変わりません）。B は、`no` を法副詞の前に置くことになり、§7 の「法副詞はマーカーの前」という並びを変えるので、おすすめしません。

`kani no` は、「できない」（`mi kani no lano.` = 私は走れない）と、同じ形になります。「できない」と「しなくてもよい」の区別は、文脈で決まります（提案004で「できる」と「してよい」を、同じ `kani` にしたときと同じ考え方です）。

## 5. 決まったあとにやること

1. `docs/grammar.md` §4 の「許可・疑問での依頼・申し出」に、平叙文の決まりと、履歴を足す。
2. 翻訳機に、次を足す。
   - 日本語: 〜てもいい（です・よ）・〜てもよい（許可）、〜てはいけない・〜てはならない（禁止）、〜なくてもいい・〜なくてもよい（不要）
   - 英語: You may（許可）、You do not have to / You need not（不要）
3. 例文集（`corpus/examples.csv`）に例文を足し、テストを追加。

## 6. この提案に含まれないもの

- 「〜てはいけません」「〜てもよろしい」など、丁寧さの段階の区別。
- 間接的な言い方（「食べてもいいと言った」）。
- 「〜しなくてはいけない」（義務）。`masi` で、すでに言える（`リンゴを食べなければならない。` = `masi ito apa.`）。
