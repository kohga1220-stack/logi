# 提案 010: 敬語（尊敬語・謙譲語・お／ご・さん／様）

状態: **決定待ち**。M1ko が Q1〜Q3 を選んだら、Claude が実装します。

## 1. 何が足りないか

提案003〜009 のたびに、「敬語・丁寧さの段階は、含めない」と書いて、先送りしてきました。いまの決まりは、次の2つだけです。

- 丁寧さは、`pilisu`（どうぞ）の有無だけで表す（`docs/grammar.md` §4）。
- 「〜です・〜ます」と「〜だ・〜る」、「おはよう」と「おはようございます」は、区別しない。

つまり、**丁寧体（です・ます）は、すでに問題なく訳せます。** 訳せないのは、敬語の動詞・接頭辞・接尾辞です。翻訳機を実際に動かして確かめた、いまの出力です。

| 入力 | 現状の出力 | 問題 |
|---|---|---|
| 先生がおっしゃった。 | `titusa [おっしゃった?].` | 尊敬語の動詞が訳せない |
| お客様がいらっしゃいます。 | `[様?] alo [お?] kesuta [いらっしゃ?].` | 「お」「様」「いらっしゃる」が訳せない。語順も崩れる |
| 召し上がってください。 | `[召し上?] [ってく?] [さい?].` | 尊敬語 + 依頼が訳せない |
| ご覧ください。 | `[ご覧く?] [さい?].` | 同上 |
| お待ちください。 | `[お待ちく?] [さい?].` | 「お + 動詞 + ください」が訳せない（「待ってください」は `pilisu, mato!` と訳せる）|
| 私が参ります。 | `mi [参ります?].` | 謙譲語の動詞が訳せない |
| 私が申し上げます。 | `mi leto [申し?].` | 同上 |
| 私は田中と申します。 | `mi topo nata [中?] e [申?].` | 同上。名前の扱いも崩れる |
| 拝見しました。 | `pasu topo [拝見?].` | 同上 |
| 田中さんが来ます。 | `[中さん?] komo nata.` | 「さん」が名前に付いたままで、名前の扱いが崩れる |
| いらっしゃいませ。 | `[いらっしゃいませ?].` | あいさつの定型句が訳せない |
| ごちそうさまでした。 | `pasu topo pisuta [さ?] [まで?].` | 同上 |
| お願いします。 | `topo [お?] wesa.` | 「お」が訳せない |

## 2. 手がかり（すでにある決まり）

- Logi は、丁寧さを文法に持たない。`pilisu` が、唯一の丁寧さの印（提案003）。
- 基本の動詞は、すでにある: 言う `juo`、食べる `ito`、見る `sio`、する `topo`、行く `iko`、来る `komo`、ある・いる `alo`、待つ `mato`、迎える `weluko`。
- 英語の Welcome. は `weluko!`、Thank you. は `mi tanako tu.`、Please は `pilisu`（提案002・005）。

## 3. 提案

### Q1. 敬語の基本方針

| 案 | 内容 |
|---|---|
| **A（おすすめ）** | **Logi に敬語の段階は作らない。** 敬語の動詞・接頭辞（お・ご）・接尾辞（さん・様）は、意味だけを訳し、敬意の部分は落とす。丁寧に頼むときだけ `pilisu` を使う（これまでどおり）|
| B | 敬語を表す印を、新しく3音節で造る（文末か文頭に置く）|
| C | 敬語は決めず、翻訳機は訳さない（いまのまま）|

おすすめは A です。理由は、Logi の目的（論理的な明確さ・文法の少なさ）に合うこと、新しい語や文法が要らないこと、日本語以外（英語）には、同じ種類の敬語がなく、どの言語からも対応が取りやすいことです。敬意の違いを訳し分ける必要が出たら、B を足せます。

### Q2. 敬語の動詞・接頭辞・接尾辞の訳し方

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 敬語の動詞を、ふつうの動詞に直して訳す。「お／ご + 動詞 + ください」は、依頼（`pilisu, 動詞!`）にする。名前や名詞に付く「お・ご・さん・様」は、落とす | 下の表 |
| B | 一部だけ（おっしゃる・いらっしゃる・召し上がる など、よく使う語だけ）対応し、あとは訳さない | |
| C | 訳さない | |

案 A の対応（すべて新しい語なし）:

| 日本語 | Logi |
|---|---|
| おっしゃる・申す・申し上げる | 言う `juo` |
| 召し上がる・いただく（食べる）| 食べる `ito` |
| ご覧になる・拝見する | 見る `sio` |
| なさる・いたす | する `topo` |
| いらっしゃる・参る | 行く `iko`（へ・に がある）／来る `komo`（から がある）／いる `alo`（それ以外）|
| お待ちください・ご確認ください | `pilisu, mato!`・`pilisu, konato!`（動詞 + ください と同じ）|
| 田中さん・田中様・お客様 | 名前・名詞だけ（`kesuta`）|

例:
```
titusa pasu juo.            （先生がおっしゃった）
mi iko.                     （私が参ります）
pilisu, mato!               （お待ちください）
kesuta alo.                 （お客様がいらっしゃいます）
```

おすすめは A です。理由は、新しい語が要らず、提案003〜006の決まり（依頼は `pilisu`）に、そのままつながるからです。「いらっしゃる」「参る」は、意味が3つあるため、助詞で見分けます（見分けられないときは `alo`）。

### Q3. 敬語の定型句（いらっしゃいませ・ごちそうさま・お願いします）

提案005 Q3 で、「専用の語を作らない」と決めた定型句のうち、敬語に近いものだけを決め直します。

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | いらっしゃいませ = `weluko!`（Welcome. と同じ）、ごちそうさま（でした）= `mi tanako tu.`（ありがとうと同じ）、お願いします = `pilisu.`。いただきます・はじめまして などは、これまでどおり訳さない | `weluko!` |
| B | これまでどおり、すべて訳さない | |
| C | 専用の感動詞を造る | |

おすすめは A です。理由は、新しい語が要らず、英語にも近い言い方（Welcome.・Thank you.・Please.）があるからです。
