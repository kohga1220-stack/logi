# 提案 007: 目的・様態・対比の接続（「〜ために」「〜ように」「〜一方」）

## 1. 何が足りないか

`docs/grammar.md` §10.4 に「未定義の接続（語の追加が必要）」として残っている項目です。目的（〜ために＋節）、方法・様態（〜ように）、同時の対比（〜一方）。

翻訳機を実際に動かして確かめた、いまの出力です。

| 入力 | 現状の出力 | 問題 |

| 勉強するために学校へ行く。 | `iko tote [ため?] ta li sutuko tote sukula.` | 「ため」が訳せない。語順も崩れる |

| 本のために行く。 | `iko pote pupa.` | これでよい形 |

## 2. 手がかり（すでにある決まり）

- 前置詞 `pote`（のために。for）が、すでに辞書にある。名詞の「〜のために」は `pote + 名詞` で言える。
- 動名詞（動詞 + `na`。§3）で、動詞を名詞にできる。例: `sutukona`（勉強すること）。
- 従属接続語は、かかる節の直前に置く（§10.3.1）。例: `pikosu A, B.`（AなのでB）。
- 並列・対比の接続語は、節の間に置く。`A, patu B.`（AだがB）。
- 機能語の新語は、3音節の空き形を、語尾 `-u` で造る（提案002 Q1）。

## 3. 提案

### Q1. 目的（〜ために・in order to・to + 動詞）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | `pote` + 動名詞（動詞 + `na`）。新しい語を作らない。主語は、主節と同じものだけ | `mi iko tote sukula pote sutukona.`（勉強するために学校へ行く）|
| B | 目的を表す接続語を、3音節で新しく造る（節をとる）| `mosulu mi sutuko, mi iko tote sukula.`（`mosulu` は案。編集距離1の語がないことを確認済み）|
| C | 目的の文型は作らず、翻訳機は訳さない | |

おすすめは A です。理由は、新しい語が要らず、名詞の「〜のために」（`pote`）の自然な延長だからです。限界は、「子どもが食べられるように作る」のように、**主語が違う**目的を言えないことです。それが必要になったら、B を足せます（提案002のときと同じ進め方）。

### Q2. 様態（〜ように・as・like）

「ように」には3つの意味があります。この提案で決めるのは、1つ目だけです。

1. 様態（言ったように・私がしたように）: as
2. 目的（食べられるように）: so that。Q1 の B で扱う
3. 願い（元気でありますように）: この提案に含めない

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 様態を表す接続語を、3音節で新しく造る（節をとる。節の直前に置く）| `kasolu li juo, mi iko.`（彼が言うように、私は行く。`kasolu` は案。編集距離1の語がないことを確認済み）|
| B | 既存の語 `atute weia`（で + 方法）で言う | `mi iko atute weia li juo.` |
| C | 様態の文型は作らず、翻訳機は訳さない | |

おすすめは A です。理由は、「as」は日常でよく使い、既存の語の組み合わせ（B）は、「方法によって」という別の意味に読めるからです。

### Q3. 対比（〜一方・〜一方で・whereas・on the other hand）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 既存の `patu`（しかし）で言う。翻訳機は、一方・一方で・whereas・on the other hand を `patu` にする | `mi ito, patu li neo.`（私は食べる一方で、彼は寝る）|
| B | 対比を表す接続語を、新しく造る | |
| C | 対比の文型は作らず、翻訳機は訳さない | |

おすすめは A です。理由は、新しい語が要らず、「しかし」と「一方」の違いは、文の内容でわかるからです。

## 6. この提案に含まれないもの

- 「〜ように」の目的（so that）と願い。
- 「ために」の原因の意味（「病気のために休んだ」）。これは理由で、`pikosu`（なぜなら）で言える。
- 主語が違う目的の節（Q1 の A では言えない）。
