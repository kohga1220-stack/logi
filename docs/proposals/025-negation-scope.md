# 提案 025: 否定の範囲（部分否定・全否定）

状態: **決定済み**。M1ko が「全て許可」と返事をしたので、Claude がおすすめの A（Q1〜Q3 すべて）を選んで実装した（v0.32）。仕様は docs/grammar.md §7 を参照。

## 1. 何が足りないか

否定の `no` は、動詞の前（`mi no ito apa.`）に置く決まりです。しかし、「みんなが来たわけではない」（全員は来ていない）と「誰も来なかった」（全員が来ていない）のように、否定がどこまで及ぶかが違う文は、いまの翻訳機では区別できません。翻訳機を実際に動かして確かめた、いまの出力です。

| 入力 | 現状の出力 | 問題 |
|---|---|---|
| 全員が来たわけではない。| `[全員?] no pio [わけ?] ta li pasu komo.` | 訳せない |
| 私はいつも肉を食べるわけではない。| `mi onuli no pio [わけ?] ta li ito.` | 訳せない |
| 彼は必ずしも来ない。| `li suli no komo.` | 「必ず来ない」（必ず + 否定）になり、意味が逆 |
| 誰も来なかった。| `kua olusi pasu no komo.` | 「誰も」が「誰も（疑問詞 + もまた）」になる |
| 何も食べなかった。| `wata olusi pasu no ito.` | 同上 |
| I do not always eat meat. | `mi aloi no ito mita.` | 「いつも食べない」（決して食べない）になり、意味が逆 |
| Not all students came. | （未対応）| 訳せない |
| Nobody came. | （未対応）| 訳せない |

## 2. 手がかり（すでにある決まり）

- 副詞は、主語の直後、マーカーの前（`mi enuti no mo.` = 全く知らない）。否定の `no` は、その後ろ。つまり「副詞 + no + 動詞」は、副詞が否定を修飾する（全く + 知らない）。
- 辞書には、みんな `ewa`、すべて `eja`、誰でも `awa`、何でも `aja`、何もない `noka`、すべての `epule`、いつも `aloi`、必ず `suli` がある。

## 3. 提案

### Q1. 部分否定（全員・全部・いつも・必ず + 否定）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | `no` は、直後の語を否定する。**数量の語・副詞の直前**に `no` を置くと、その語だけの否定（部分否定）。動詞の前に置くと、動詞の否定（全否定）。新しい語は要らない | `no ewa pasu komo.`（みんなが来たわけではない。Not everyone came）<br>`no epule sutua pasu komo.`（すべての学生が来たわけではない）<br>`mi no aloi ito mita.`（いつも肉を食べるわけではない）<br>`li no suli komo.`（彼は必ずしも来ない）|
| B | 部分否定用の語を造る | |
| C | 決めない | |

おすすめは A です。理由は、新しい語が要らず、`no` の位置が「何を否定するか」を表す一つの規則で済むからです（`副詞 no 動詞` = 副詞を否定の中に含める、`no 副詞 動詞` = 副詞を否定する）。

### Q2. 全否定（誰も・何も + ない）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 誰も = `awa`（誰でも）、何も = `aja`（何でも）。述語を `no` で否定する | `awa pasu no komo.`（誰も来なかった。Nobody came）<br>`mi pasu no ito aja.`（何も食べなかった）|
| B | `noka`（何もない）を使う | `mi pasu ito noka.` |
| C | 決めない | |

おすすめは A です。理由は、Q1 と同じ規則（`no` は述語の前なら全否定）で、「誰でも来なかった」＝誰も来なかった、と読めるからです。`noka`（何もない）は名詞のままです（`mi pasu ito noka.` は I ate nothing として、これまでどおり）。

### Q3. 〜わけではない・〜とは限らない

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 「わけ」「とは限らない」は訳さず、前の節を否定する。節に数量の語・いつも・必ず があれば、その語の直前に `no`（Q1）。なければ、節の述語の否定 | `mi no ito mita.`（肉を食べるわけではない）<br>`no suli pio ile.`（高いとは限らない）|
| B | 専用の語を造る | |
| C | 決めない | |

おすすめは A です。理由は、新しい語が要らず、日本語の「わけではない」は、前の節の否定と同じ働きだからです。

## 6. この提案に含まれないもの

- 〜だけではなく〜も（not only ... but also）。別に決める。
- 「どこにも」「一度も」（`wela`・回数の否定）。別に決める。
- 何も + 自動詞（何も起こらなかった）の日本語入力。「何も」は、いまは目的語（を）として扱う。英語 `Nothing happened.` は主語として訳せる。
