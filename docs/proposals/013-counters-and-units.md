# 提案 013: 助数詞・順序数・単位（3個・2匹・3回・3番目・10キロ）

## 1. 何が足りないか

`docs/grammar.md` §5 は、数詞と「数 + 単位 = 数量」（`mi oto to ila.` = 私は2歳）まで決めています。助数詞（個・匹・冊 など）・順序数（3番目）・長さや重さの単位は、決めていません。翻訳機を実際に動かして確かめた、いまの出力です。

| 入力 | 現状の出力 | 問題 |
|---|---|---|
| リンゴを3個食べる。 | `ito apa te [個?].` | 「個」が訳せず、語順も崩れる |
| 犬が2匹いる。 | `tuka alo to [匹?].` | 「匹」が訳せない |
| 本を3冊読む。 | `loto pupa te [冊?].` | 同上 |

| 3番目の家。 | `te [番?] aia usa.` | 順序数が訳せない |

## 2. 手がかり（すでにある決まり）

- 数は、名詞の前に置く（`te apa` = 3つのリンゴ。§5）。複数は `mene`（多くの）で、数が分かるときは数詞だけ。
- 数 + 単位の語 = 数量（`to ila` = 2年間、`te taima` = 3回）。
- 通貨は `jena`（円）がある。`kosuto` の文で使える（`li kosuto pa kupulu jena.`）。
- 順序の語 `semuna`（順序）が辞書にある（v0.8）。

## 3. 提案

### Q1. 助数詞（個・匹・冊・本・枚・台・頭・羽・杯・人）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | **Logi には助数詞を作らない。** 数は名詞の前に置き、助数詞は落とす。日本語の「本・冊・匹」などは、数のあとにあるとき助数詞として読み、名詞の「本」にしない | `mi ito te apa.`（リンゴを3個食べる）<br>`tuka alo to.`（犬が2匹いる。名詞が前にあるとき、数だけ）<br>`penusa alo pe.`（鉛筆が5本ある）|
| B | 助数詞を表す語を、新しく3音節で造る（数のあとに置く）| |
| C | 助数詞は決めず、翻訳機は訳さない（いまのまま）| |

おすすめは A です。理由は、新しい語が要らず、英語（three apples）と同じ作りで、Logi の「文法を少なく」という方針に合うことです。種類（ものの数え方）の情報は落ちますが、名詞が種類を表しているので、意味は失われません。

### Q2. 順序数（3番目・第3・third）と回数

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 新しい語は造らず、`semuna`（順序）を名詞の**あと**に置き、そのあとに数を置く。回数（〜回・〜度）は、数量の `te taima`（これまでどおり）| `aia semuna te.`（3番目の家。the third house）<br>`mi pasu iko te taima.`（3回行った）|
| B | 順序数を表す語（〜番目）を、新しく造る | |
| C | 順序数は決めず、訳さない（いまのまま）| |

おすすめは A です。理由は、新しい語が要らず、「家の順序は3」という意味が、そのまま見えるからです。

### Q3. 単位の語（キロ・メートル・グラム・リットル・パーセント）

| 案 | 内容 | 例 |
|---|---|---|
| **A（おすすめ）** | 単位は、ふつうの名詞として語を足す（Antigravity に依頼: meter・kilometer・gram・kilogram・liter・percent など）。使い方は、数 + 単位の語（通貨の `jena` と同じ）。翻訳機は、数 + 単位の語を、助数詞として落とさず、そのまま訳す | `lano pa pulu kilometa.`（10キロ走る。語形は造語ツールが決める）|
| B | 単位は、数のあとに付ける短い印（接尾辞）にする | |
| C | 単位は決めず、`[語?]` のまま残す（いまのまま）| |

おすすめは A です。理由は、`jena`（円）と同じ作りで、新しい文法が要らないことです。語の数が増えるので、造語は `tools/coin_words.py` を使い、確認表で確認します。「倍」「半分」「〜分の1」は、この提案に含めません。
