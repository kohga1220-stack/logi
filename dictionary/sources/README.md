## 候補の選び方（v0.8）

`python tools/core_candidates.py` が、次の基準で「辞書にまだ無い語」を出します。

1. 6つのリストのうち5つ以上に採用されている
2. 国語研教育基本語彙で◎（基本）の語
3. 接尾辞・接頭辞・感動詞・助詞・連語は除く

最初の実行では1,103語が候補になりました。追加後に実行すると、残りは555語です（次の理由で入れなかった語を含みます）。次の語は、Logi では複合語や既存の語で言えるため入れていません。

- 数詞・日付の数え方（ここのか・ようか・ひとつ・ふたり など）
- 敬語（いらっしゃる・いたす・うかがう など）
- 「今年・来月・毎朝」のような複合語（`今 + 年` の形で言う。docs/grammar.md §10.2）
- ひらがな・かたかなの名前
- 指示詞（これ・あれ・ここ）、はい／いいえ、疑問の「いくつ・いくら」（文法に枠がないため、設計が決まってから足す）

残りの語に、英語・品詞・日本語の意味を付けたものが `dictionary/core_additions.csv` です。
既存の語と同じ意味になる語は入れていません（`source` 列に元の見出しを残しています）。
英語・日本語の意味は Claude が書いた案で、人の確認を受けていません。

`kyoikukihongoi_2009A.csv` は、阪本などの区分を調べるために置いています。選定には `rokusyutaisyo.csv` の採用数を使いました。
